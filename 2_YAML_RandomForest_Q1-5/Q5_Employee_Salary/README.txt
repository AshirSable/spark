Q5: Employee Salary Prediction
Install once:  pip install pyyaml scikit-learn joblib pandas openpyxl
Run:           python train.py   (in this folder)
The dataset Employee_Salary_Data.xlsx is your exam file. openpyxl is needed to read .xlsx.
Education_Level is encoded Diploma=0, Bachelors=1, Masters=2, PhD=3 (the file contains exactly these four). The question's 'Bachelor's degree' = Bachelors.
