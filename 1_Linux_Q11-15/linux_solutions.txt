LINUX COMMANDS - SOLUTIONS FOR Q11 TO Q15
Run in the LabEx terminal. Type one line at a time, press Enter, compare with the output.
Lines starting with $ are what you type. The lines under them are what you should see.
No output = the command worked.
Outputs below are from a real run on Ubuntu. Your user name, dates, sizes and PIDs will differ.

======================================================================
Q11: File and Directory Navigation
======================================================================
a) Display the present working directory
$ pwd
/home/labex

b) List all files, including hidden files
$ ls -a
.  ..
(on LabEx you will also see hidden files such as .bashrc and .profile)

c) Navigate to the /home directory
$ cd /home
$ pwd
/home

d) Create a directory structure of your choice
$ mkdir -p ~/ml_project/data/raw ~/ml_project/models
$ ls -R ~/ml_project
/home/labex/ml_project:
data  models

/home/labex/ml_project/data:
raw

/home/labex/ml_project/data/raw:

/home/labex/ml_project/models:

e) Return to the home directory
$ cd ~
$ pwd
/home/labex

(-p creates the parent folders too. cd ~ or just cd goes home.)

Q12: File and Directory Management
======================================================================
a) Create a directory named Linux_Practical
$ mkdir Linux_Practical

b) Inside it, create Documents, Scripts and Backup
$ mkdir Linux_Practical/Documents Linux_Practical/Scripts Linux_Practical/Backup
$ ls Linux_Practical
Backup  Documents  Scripts

c) Create student.txt inside Documents
$ touch Linux_Practical/Documents/student.txt

d) Copy student.txt into Backup
$ cp Linux_Practical/Documents/student.txt Linux_Practical/Backup/

e) Rename the copied file to student_details.txt
$ mv Linux_Practical/Backup/student.txt Linux_Practical/Backup/student_details.txt
$ ls Linux_Practical/Backup
student_details.txt

f) Delete the copied file and remove the empty Scripts directory
$ rm Linux_Practical/Backup/student_details.txt
$ rmdir Linux_Practical/Scripts
$ ls -R Linux_Practical
Linux_Practical:
Backup  Documents

Linux_Practical/Backup:

Linux_Practical/Documents:
student.txt

(rmdir only removes EMPTY folders. The original student.txt in Documents is untouched.)

Q13: Viewing and Editing File Contents
======================================================================
a) Create employee.txt with five employee records
$ printf '101 Rahul Sharma 50000\n102 Priya Patel 62000\n103 Amit Verma 55000\n104 Sneha Rao 48000\n105 Karan Mehta 71000\n' > employee.txt

   (or type it in an editor:  nano employee.txt  then Ctrl+O, Enter, Ctrl+X)

b) Display the complete contents
$ cat employee.txt
101 Rahul Sharma 50000
102 Priya Patel 62000
103 Amit Verma 55000
104 Sneha Rao 48000
105 Karan Mehta 71000

c) First three lines
$ head -n 3 employee.txt
101 Rahul Sharma 50000
102 Priya Patel 62000
103 Amit Verma 55000

d) Last two lines
$ tail -n 2 employee.txt
104 Sneha Rao 48000
105 Karan Mehta 71000

e) Count lines, words and characters
$ wc employee.txt
  5  20 108 employee.txt
(columns: lines, words, characters, file name)
$ wc -l employee.txt
5 employee.txt
$ wc -w employee.txt
20 employee.txt
$ wc -c employee.txt
108 employee.txt

f) Search for a specific employee name
$ grep "Priya" employee.txt
102 Priya Patel 62000

g) Append one more employee record
$ echo "106 Neha Singh 58000" >> employee.txt
$ cat employee.txt
101 Rahul Sharma 50000
102 Priya Patel 62000
103 Amit Verma 55000
104 Sneha Rao 48000
105 Karan Mehta 71000
106 Neha Singh 58000

(>> adds to the end. A single > would overwrite the whole file.)

Q14: File Permissions and Process Management
======================================================================
a) Create a file named script.sh
$ touch script.sh

b) Display its current permissions
$ ls -l script.sh
-rw-rw-r-- 1 labex labex 0 Oct 22 07:25 script.sh
(rw- owner, rw- group, r-- others)

c) Give the owner read, write and execute
$ chmod u+rwx script.sh
$ ls -l script.sh
-rwxrw-r-- 1 labex labex 0 Oct 22 07:25 script.sh

d) Remove write permission for others
$ chmod o-w script.sh
$ ls -l script.sh
-rwxrw-r-- 1 labex labex 0 Oct 22 07:25 script.sh
(Others already had no write permission, so the line looks the same. The command is still the correct answer. If others had write (rwx), you would see it disappear. Number form: chmod 754 script.sh gives rwxr-xr--.)

e) Display the running processes
$ ps
  PID TTY          TIME CMD
  348 ?        00:00:00 bash
  378 ?        00:00:00 ps
(For all processes: ps aux)

f) Execute a command in the background and check the running jobs
$ sleep 300 &
$ jobs
[1]+  Running                 sleep 300 &
(A line like [1] 4321 may appear after the first command: job number and PID.)

g) Terminate the background process
$ kill %1
$ jobs
[1]+  Terminated              sleep 300
(or use the PID: find it with ps, then kill 4321. kill -9 4321 forces it.)

%Cpu(s):  0.0 us,  3.2 sy,  0.0 ni, 80.6 id, 16.1 wa,  0.0 hi,  0.0 si,  0.0 st

d) Available disk space
$ df -h
Filesystem      Size  Used Avail Use% Mounted on
/dev/vda        252G   22G   22G  51% /
(more lines will appear on LabEx. Look at the Avail column.)

$ du -sh .
44K	.

f) Five largest files or directories within a specified directory
$ du -ah ~/Linux_Practical ~/ml_project | sort -rh | head -5

(may print nothing in some sandboxes. Also try:  whoami   or   w)

SPEED TIPS
======================================================================
- pwd and ls whenever you are unsure where you are.
- Tab completes file names. Up arrow repeats the last command.
- Stuck screen? q (top, less), Ctrl+C (sleep, ping, tail -f).
